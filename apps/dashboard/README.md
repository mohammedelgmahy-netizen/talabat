# لوحة تحكم طلبات (Next.js + Tailwind)

لوحتين في تطبيق واحد، وكل مستخدم بيتوجه حسب دوره:

- **/admin** — للأدمن: إحصائيات المنصة، خريطة حية للسائقين والطلبات، كل الطلبات (إلغاء / إسناد سائق)، الموافقة على المتاجر وتحديد العمولة، توثيق السائقين، إيقاف المستخدمين، إعدادات المنصة.
- **/store** — لصاحب المتجر: إحصائيات ومستحقات، لوحة طلبات لحظية بتنبيه صوتي (قبول/رفض/تحضير/جاهز)، سجل الطلبات، المنيو والأقسام ورفع الصور، بيانات المتجر وموقعه على الخريطة ومواعيد العمل.

## التشغيل

```bash
cp .env.example .env.local     # واملأ رابط المشروع والمفتاح العام
npm install
npm run dev                    # http://localhost:3000
```

للإنتاج: `npm run build && npm start` أو ارفعه على Vercel وضع نفس المتغيرين في إعدادات المشروع.

## ملاحظات

- اللوحة بتستخدم المفتاح العام فقط؛ كل الصلاحيات محمية بالـ RLS والدوال في قاعدة البيانات.
- أول أدمن يتعمل يدوياً: سجّل حساب عادي ثم نفّذ في SQL Editor:
  `update public.profiles set role = 'admin' where email = 'you@example.com';`
- التحديثات اللحظية تعتمد على Supabase Realtime (الجداول مضافة للـ publication في ملفات SQL).
